# 01. 要件一覧

基本設計(00)の機能 F1〜F8 と非機能 N1〜N4 を、テスト可能な粒度の要件に分解して要件IDを付ける。
各要件と設計・テストの対応は [09_traceability.md](./09_traceability.md) を参照。

## 1. 機能要件

| 要件ID | 機能 | 要件 | 受入れ基準(要約) |
|---|---|---|---|
| REQ-001 | F1 | 支出を登録できる(日付・金額・カテゴリ・メモ) | 正しい入力は201で保存される。不正な入力は400で、保存されない |
| REQ-002 | F1 | 支出を編集できる | 指定IDの全項目を置き換える。存在しないIDは404 |
| REQ-003 | F1 | 支出を削除できる | 削除後は一覧・集計に出ない。存在しないIDは404 |
| REQ-004 | F1 | 支出を月単位で一覧表示できる | 指定月の支出が日付の降順で並び、月合計が付く |
| REQ-005 | F2 | カテゴリ(固定+ユーザー追加)を一覧表示できる | 固定8件は常に存在する。表示名は言語に追従する |
| REQ-006 | F2 | ユーザーカテゴリを追加できる | 名前は1〜30文字。重複名は409 |
| REQ-007 | F2 | 未使用のユーザーカテゴリを削除できる | 使用中は409(CATEGORY_IN_USE)、固定カテゴリは409(CATEGORY_FIXED) |
| REQ-008 | F3 | サブスクを登録・編集・削除・一覧表示できる | 名称・金額・周期・次回更新日を管理できる |
| REQ-009 | F3 | サブスクを停止・再開できる | 状態遷移図(DATA-04)以外の遷移は409 |
| REQ-010 | F3 | 「更新済み」操作で次回更新日を再計算できる | 月末・うるう年・31日起点の規則(BR-03)に従う |
| REQ-011 | F4 | 今日から7日以内の更新予定と、更新日を過ぎたものを表示できる | 有効なサブスクだけが対象。残り日数が付く |
| REQ-012 | F5 | 月次のカテゴリ別合計と月合計を表示できる | 月の境界は BR-02 に従う |
| REQ-013 | F5 | 前月比(差額・増減率)を表示できる | 前月が0円のときは増減率を表示しない(BR-06) |
| REQ-014 | F5 | サブスク合計(月額換算)を表示できる | 年次は÷12で切り捨て(BR-04) |
| REQ-015 | F5 | カテゴリ別の円グラフと、直近6か月の棒グラフを表示できる | 0件のときは「データなし」と表示する |
| REQ-016 | F6 | 全体予算とカテゴリ別予算を設定できる | 0〜99,999,999円。0は未設定扱い |
| REQ-017 | F6 | 予算の消化状況を判定し、注意・警告を表示できる | 80%以上で注意、100%を超えたら警告(BR-05) |
| REQ-018 | F7 | CSVで支出を一括で取り込める | UTF-8 / UTF-8(BOM付き)/ Shift_JIS に対応 |
| REQ-019 | F7 | 不正行・重複行をスキップし、結果レポートを返す | 行番号とエラーコードを返す。正しい行だけ取り込む |
| REQ-020 | F8 | UIを英語/日本語で切り替えられ、選択を記憶する | デフォルトは英語。localStorage から復元する |
| REQ-021 | F8 | 日付・金額・グラフのラベルを言語に応じた形式で表示する | 英語:Oct 23, 2026 / ¥1,200、日本語:2026年10月23日 / 1,200円 |
| REQ-022 | F8 | APIエラーをエラーコードで受け取り、選択言語の文言で表示する | APIは言語に依存しないコードだけを返す |
| REQ-023 | F8 | 翻訳辞書(en/ja)のキーが一致している | テストで過不足を検出できる |

## 2. 非機能要件

| 要件ID | 区分 | 要件 | 受入れ基準(要約) |
|---|---|---|---|
| NFR-001 | 性能 | API応答は500ms以内 | 支出5,000件の状態で、集計APIが500ms以内に応答する |
| NFR-002 | 入力検証 | 不正入力はすべて4xxで、統一エラー形式で返す | FastAPI標準の422形式を返さない |
| NFR-003 | 可用性 | データファイルの破損・欠損時も起動できる | 破損ファイルを退避して初期データで起動し、画面に警告を出す |
| NFR-004 | 可搬性 | ネットワーク未接続でも全画面を表示・操作できる | CDN参照がない。vendorファイルを同梱している |
| NFR-005 | 整合性 | 同時リクエストでもJSONファイルが壊れず、更新が失われない | 並行書き込み後の件数が一致する |
| NFR-006 | 正確性 | 金額を浮動小数点で扱わない | 金額はすべて整数。率は Decimal で計算する |
| NFR-007 | 保守性 | 業務ルールはバックエンドの純粋関数に置き、フロントに計算ロジックを置かない | `app/domain/` に集約する。単体テストで直接検証できる |
