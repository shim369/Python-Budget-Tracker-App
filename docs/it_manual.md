# 結合テスト 手動確認手順書(MT)

自動化しにくい画面の見え方・グラフ・言語切替・オフライン動作を、手順書として確認する。

| 項目 | 内容 |
|---|---|
| 実施日 | 2026-10-23 |
| 実施者 | Claude(Claude in Chrome によるブラウザ操作)。MT-04 の手順4のみ、利用者の実施が必要(後述) |
| 環境 | macOS、Google Chrome、`uv run uvicorn app.main:app`(単一プロセス)、ダークテーマ |
| データ | `data/sample.json` の一時コピー(`BUDGET_DATA_FILE` で指定)。必要に応じて API で追加した |
| 判定 | 合格 / 不合格(→ バグ票)/ 未実施 |

## 準備

```bash
cp data/sample.json /tmp/budget.json
BUDGET_DATA_FILE=/tmp/budget.json uv run uvicorn app.main:app
# ブラウザで http://127.0.0.1:8000/ を開く
```

> 「今日」はサーバーの日付(JST)になる。サンプルデータは 2026-10-23 前後を想定している。日付が離れている場合、ダッシュボードの「今月」は空になるので、◀ ボタンで 2026年10月 に移動して確認する。

## MT-01 全画面の表示(REQ-001〜019 の画面、SCR-00〜05)

| No | 操作 | 確認内容 | 結果 |
|---|---|---|---|
| 1 | localStorage を消してから開く | 英語で表示される(既定の言語) | 合格 |
| 2 | 5画面(Dashboard / Expenses / Subscriptions / Budgets / Import)を順に開く | 各画面が表示され、データが入る。アドレスバーのハッシュとナビゲーションの選択状態が一致する | 合格 |
| 3 | 日本語に切り替えて5画面を開く(幅 1280px) | 見出し・日付・ボタンが1文字ずつ折り返されない。表が枠からはみ出さない | **初回は不合格 → BUG-002**。修正後に合格 |
| 4 | 幅 390px で、ダッシュボード・サブスク・支出を開く | ヘッダーは項目単位で折り返す。表は横スクロールで表示される | **初回は不合格 → BUG-002**。修正後の再テストで **BUG-003** を発見。両方を修正後に合格 |

**既知の制約(不具合として扱わない)**:
`<input type="month">` / `type="date"` / `type="file"` の表示(「2026年10月」「ファイルを選択」など)は、アプリの言語ではなくブラウザの言語設定に従う。ブラウザ標準の部品であり、アプリから表示言語を変えられないため。独自の部品に置き換える案は、拡張案に記載する。
