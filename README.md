# Python-Budget-Tracker-App

A lightweight budget & subscription tracker built with FastAPI.
UI is English by default, with a Japanese language toggle.

## Features (planned)
- Expense tracking and category summary
- Subscription management with renewal reminders
- Monthly budget alerts
- CSV import

## Tech Stack
Python 3.12 / FastAPI / Pydantic / pytest / HTML5 / CSS / JavaScript / REST API (JSON)

## Getting Started
```bash
uv sync
uv run uvicorn app.main:app --reload
```
